# Terrain Analysis

Use for DEM acquisition, raster clipping/reprojection, slope calculation, and
terrain statistics. Require a region/AOI. Expose only boundary, DEM, slope,
statistics, geometry validation, projection, and clipping capabilities. Return
CRS, resolution, units, source version, checksum, and provenance. Do not call
site ranking, infrastructure, remote-sensing VLM, or unrelated map tools.
